# PixelCode

Sistema interno de gestão para barbearias. O barbeiro e sua equipe usam a aplicação para organizar clientes, serviços, agendamentos e pagamentos. O cliente é um contato externo e não acessa a plataforma.

## Tecnologias

- Backend: Xano
- Frontend: Reflex 0.9.12
- Especificação de mudanças: OpenSpec

## Executar o frontend

A partir da pasta `frontend`, instale as dependências listadas em `requirements.txt` e execute `reflex run`.
